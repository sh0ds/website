Quick exercises

Small exercises I do on my work PC when I have 10 to 15 free minutes.

I can't install anything there, so it all happens in the browser: plain Lua on the lua.org demo and PICO-8 on pico-8-edu.com, the free Education Edition. Every one starts from an empty cart, uses only shapes (no sprites, no map) and fits on one screen of code. All the code is in sh0ds/pico8.

PICO-8

E3 · A moment of colour

Press ❎: the screen flashes white for 2 frames and the score goes up by 100 and turns orange for 8.

btnp instead of btn, so holding ❎ doesn't flash every frame. _update runs before _draw, so tick the timers first, then set them, or one frame gets lost. poke(0x5f5c, 255) turns off btnp's auto-repeat, found that one myself.

E4 · Particles

Press ❎: 20 particles burst out of the middle, fall and shrink until they're gone.

Name the fields ({x = x}) instead of [1]. PICO-8 has no table library, it's add and deli. Angle and speed are separate: cos(angle) * speed. A full turn goes from 0 to 1, and sin is flipped. Gravity goes on dy, not on y: adding to y is wind, adding to dy makes arcs.

E5 · Shake without a shaky HUD

Same particles, but now the screen shakes and the counter in the corner stays still.

_draw runs once per frame, so a loop in there plays the whole shake in one frame. Count down in _update, drawing only reads the state. camera stays set until the next call: shake, draw the world, camera(), then draw the HUD. My own pattern: left, still, right, with tick going 0, 1, 2.

E5b · Random shake

E5 with a random shake.

shake is the strength and gets multiplied by 0.8 every frame in _update, so it hits hard and calms down smoothly. _draw picks a random offset from it, x and y separately. rnd(0) is 0, so no if needed.

E7 · A map without the map editor

A 16×16 map written as strings of 0s and 1s, drawn as 8×8 squares, and a dot that can't go into walls.

sub(s, i, i) gives back one character, and it's a string ("1", not 1). Grid to pixel is (j - 1) * 8, pixel to grid is flr(px / 8) + 1. Check before moving, x and y separately, so you slide along walls instead of sticking. And check the edges of the dot, not its centre. Don't name a table map.

E9 · A coin that spins

An oval whose width follows abs(cos(tick / 40)), so it looks like a turning coin.

Bigger number, slower spin. abs mirrors the negative half, so the coin shows its edge twice per turn, like a real one. max(1, ...) keeps it from disappearing. Centre first, then half the width out each way. sin only goes from -1 to 1, so multiply it to get a bob you can see.

Lua

L1 · Borders

A list of five items, the third one gets removed, and everything after it moves down by one, by hand.

t = {1, 2, 3, 4, 5}
del = 3
for i=del,#t do
    t[i] = t[i+1]
end
print(#t)

No if needed: reading one past the end gives nil, so the last step clears the last slot by itself. t[3] = nil is a trap in a list, which is why PICO-8 has del. And del is a PICO-8 function, so don't use it as a variable name in a cart.

L3 · Countdown timers

A table of effect timers (flash, pop) that count down by one every frame, simulated for 12 frames.

fx = {
    ["flash"] = 0,
    ["pop"] = 0
}

frames = 12

function tick_fx()
    for key, value in pairs(fx) do
        if fx[key] > 0 then
            print(key)
            fx[key] = fx[key] - 1
        end
    end
end
for i=0,frames do
    print("frame "..i)
    if i == 2 then
        fx["flash"] = 2
    end
    if i == 5 then
        fx["pop"] = 8
    end
    tick_fx()
end

Write through fx[key], because value is only a copy. Check first, then subtract, and only above 0. One call per frame, the frame loop stays outside.

L4 · Removing while looping

Ten particles losing one life per frame, the dead ones get removed inside the loop.

particles = {
    {life = 10},
    {life = 5},
    {life = 8},
    {life = 7},
    {life = 2},
    {life = 4},
    {life = 9},
    {life = 3},
    {life = 6},
    {life = 1}
}

for i=1,10 do
    for j=#particles,1,-1 do
        particles[j].life = particles[j].life - 1

        if particles[j].life <= 0 then
            table.remove(particles, j)
        end
    end

    print("frame "..i)

    for g=1,#particles do
        print(particles[g].life)
    end
end

Going up skips items, because table.remove shifts everything after it down. Going backwards fixes it: those items were already visited. A for only counts down if you give it a third number (-1), and changing the loop variable inside a for does nothing. Test with dead items right next to each other, like {1, 1, 1, 2, 2, 3}.
