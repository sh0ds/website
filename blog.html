3sgc - building a static site generator in C

September 23, 2026

new project! I'm writing my own static site generator in C: 3sgc (that's SSSGC - sh0ds static site generator (in) C). it's my first big C project, so I'm taking it slow and building it piece by piece.

the plan: write posts in markdown, put them into html templates and get a finished site out. which means one day this blog won't be hand-written anymore 👀

so far there's the project skeleton (Makefile with address sanitizer turned on, which already saved me a few times), a binary-safe file copy function, directory walking with opendir/readdir and stat, and a recursive copy for the static folder (css, images, etc.).

things I learned the hard way: never pass file content as a format string. my first copy function looked like this: 

fprintf(f_dst, str); // breaks on the first % in your css

also: fread returning less than you asked for is not an error, it's just the end of the file. and readdir gives you . and .. too, which is a great way to recurse forever.

next up: markdown to html, front matter and templates. repo is here if you want to follow along!

The Pi-Monitor

June 9, 2026

I made a live CPU/RAM monitor you can embed in your website! (see lower right corner 👀)

There are no requirements, as it uses only pre-installed/Pi-packages.

Check out the GitHub repo if you want to embed it in your own Pi-hosted page,

To install, simply put the files into your website folder and paste this into the html-page you want it in:

<div class="pi-monitor-card">
<img src="pim-logo.png">
<p id="pi-stats">Loading Pi5 stats...</p>
</div>

the pi-monitor

                    June 9, 2026
                    

                        I made a live CPU/RAM monitor you can embed in your website! (see lower right corner 👀)
                        no requirements, it only uses pre-installed Pi packages.
                    

                    

                        check out the GitHub repo if you want to embed it
                        in your own Pi-hosted page. to install, put the files into your website folder and paste this
                        into the html page you want it in:
                    

                    
<div class="pi-monitor-card">
    <img src="pim-logo.png">
    <p id="pi-stats">Loading Pi5 stats...</p>
</div>

<script src="pi-monitor.js"></script>

                    

                        (see this website or test_page.html in the repo for examples)
                    

                    

                        currently it only works on a Pi, because the bash script uses vcgencmd for the
                        temperature. I plan to extend compatibility in the near future. (maybe not)
