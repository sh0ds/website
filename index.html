// who
sh0ds — hobby developer

// what
this site is generated by 3sgc, a static site generator i
wrote in c11 over a weekend that refused to end. no
dependencies, no plugin system, no config files written
in yaml-adjacent despair. it reads markdown, spits out
html, and gets out of the way.

// where
rasberry-pizian — a raspberry pi 5 running debian,
humming on my desk. nginx serves the files, a cron job
scribbles stats into a tmpfs ramdisk so the sd card
doesn't die, and a dns-only vpn tunnel keeps things honest.
